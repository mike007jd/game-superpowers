# Repository facts

- `skills/game-superpowers/SKILL.md` is the single skill entrypoint.
- Its `references/` directory contains gameplay, presentation, player-experience and runtime guidance.
- The npm-distributed `skills` CLI installs directly from this repository.
- `README.md` and `README.zh-CN.md` document installation and use.
- `evals/evals.json` holds behavior test prompts; update it when the skill's guidance changes.
